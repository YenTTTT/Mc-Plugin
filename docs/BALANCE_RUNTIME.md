2026-10-23 更新：自製武器改為依持有者的 RPG 等級顯示需求。未達門檻保留「等級需求」，達到門檻（含相同等級）即隱藏；交給較低等級的玩家會補回。登入、升級／管理員調級、切換主副手、拾取與背包交易完成後刷新。只更新武器說明，原等級限制仍由戰鬥檢查執行；共享配方與商人樣品保留完整需求提示。

此項新增9個回歸案例，完整 `mvn verify`：**643 tests，0 failures／errors／skipped**；紀錄 `target/weapon-level-lore-verify.log`。NEEDS_VERIFICATION：Paper 客戶端升級及轉交後的即時顯示。以下保留戰鬥 v2 的部署與歷史驗證紀錄。

2026-10-18。**COMPLETED：程式接線、版本遷移、離線驗證與 JAR；NEEDS_VERIFICATION：Paper 實機、插件相容與遊玩平衡。**

已依使用者要求，將 [Lv.1～60 初始模型](INITIAL_BALANCE_MODEL.md) 接到實際戰鬥。新版本預設啟用；原理表格是無種族、無額外天賦的標準參考線，實際種族／裝備／技能效果由以下預算控制。本輪沒有連線到正在運行的伺服器，也沒有直接修改伺服器玩家檔案。

## 1. 更新方式

1. 停服，保存原 JAR 及插件資料夾／世界存檔的伺服器備份。
2. 以新 `target/CustomRPG-1.0.jar` 替換插件 JAR，再啟動。使用完整重啟，讓存檔、模板與事件監聽順序一起切換。
3. 玩家下次載入資料時自動遷移；已載入的怪物在插件啟動時更新，其他怪物在實體載入時更新。程式不為此強制載入區塊。
4. `/stat`、`/rpg gui`、`/race info` 與選單核對新屬性。自然生怪替換仍沿用 `/finishrpg`；數值模型本身會套到既有自製怪與原版 `Enemy`，不依靠該指令解鎖。

裝備、武器、怪物、種族的既有 YAML 不會被批次覆寫；載入器按 ID 與等級產生新戰鬥數值。管理員設定的舊 `base-damage`、稀有度巨大倍率、種族大額成長等，會受到新公式／預算約束。資料夾仍可用來定義名稱、模型、掉落、技能、等級門檻與種族取向。

## 2. 玩家與存檔遷移

| 項目 | v2 行為 |
|---|---|
| 等級 | 正常成長最高 Lv.60；經驗需求維持 `L×100` |
| 升級 | 每級 3 自由點、1 天賦點，不再六項各 +1 |
| 配點 | 每點 +1 屬性，六項自由屬性＋未花點數的正常總預算為 `3×(L−1)` |
| 最大 HP | `100＋8×(L−1)＋3×總VIT＋平坦HP`；沿用專案原生 HP 上限 1024，極端全體力可能達上限 |
| 最大 MP | `80＋2×(L−1)＋2×總SPR＋裝備／種族／天賦MP` |
| 回魔 | `1.5＋0.025×(L−1)＋0.06×總SPR`，再加受限的來源加成 |
| 防禦 | 總 DEF 與有限額外評分，`min(60%, DEF/(DEF＋60＋2L))` |
| 來源分離 | 自由配點持久保存；裝備、種族、天賦、變身的來源各自重算，天賦不再加回持久自由屬性 |
| 變身 | 暫時 HP 加成最多基準 HP 的 15%；結束按當前等級／裝備重算，保留血量比例 |

首次讀到沒有 `stats.balance-version: 2` 的玩家檔時：

- 先把原始檔案逐位元備份到 `plugins/CustomRPG/data/balance-backups/v2/players/`。檔名含原檔名與 SHA-256；備份不覆寫，重試會驗證內容一致。
- 將 STR／MAG／AGI／VIT／DEF／SPR／未花點數視為七個權重，用最大餘數法分配到新預算，保留相對取向。舊格式混有自動成長、天賦與管理員給點，無法精確辨識原本手動配點；這是有備份的近似轉換。
- 例：Lv.60 舊資料 STR500／VIT200／未花300，轉成 STR89／VIT35／未花53，合計177。
- 舊 Lv.60 以上轉成60，當級溢出經驗歸零；原等級、經驗、屬性仍在原始備份中。
- MP 按原先比例轉換，避免舊 MP 數字直接被裁成新滿魔。50% 舊 MP 轉換後仍約50%（後續種族／裝備重算可能改變最大值）。
- 種族 ID、已學天賦與選取技能保留；舊未花天賦點最多保留59。舊角色可能保留超過新成長預算的歷史解鎖，但其屬性／傷害仍走新上限，沒有自動清空天賦。
- 原子寫入新玩家檔並記錄版本。再次登入／重啟不重分配。無法解析、備份失敗、未知較新版本或寫入失敗時，保留原檔並阻擋該角色進入戰鬥；登入時提示管理員處理。

天賦檔首次保存 v2 時也先備份到 `data/balance-backups/v2/talents/`。不修改原本種族選擇檔。離線玩家採下次讀取時遷移，並非啟動時把全部玩家載入記憶體。

`/rpg setlevel` 限制1～60，並按比例重新換算自由點預算。直接使用管理員的屬性／點數調整權限屬於調試操作，可以偏離正常遊戲配點。

## 3. 裝備、武器與種族

### 裝備

- 工坊980件、既有裝備模板與原版裝備轉換都採等級預算；武器格不再額外送一套護甲屬性。
- 六格參考為頭／胸／腿／腳／一戒／項鍊。整套主攻、體力、防禦仍為 `floor(.4n)`／`floor(.2n)`／`10＋floor(.5n)`。每格至少有1防禦，避免賣出完全沒有屬性的初階戒指；其餘用最大餘數法分配。
- 額外飾品格、符文、強化與套裝的六屬性總額，受當級整套預算的110%上限約束；平坦 HP 最多基礎 HP 的5%，額外防禦評分最多5。不同部位／地形仍可偏向不同流派。
- 高於玩家需求等級的裝備不給 RPG 屬性；高等武器不能攻擊或發射。原版材質映射有效等級：木／皮1、石／金／鎖鏈8、鐵18、三叉戟28、鑽石／重錘38、獄髓58。
- 裝備 ID、原物品數量、耐久、附魔、名稱與持久資料保留；舊數值不再從 lore 讀取。持有／換手／開啟背包相關介面時，延後一 tick 更新玩家背包內已知自製物品的數值 lore。
- 舊商人商品按新模板重建結果，保留交易的已用次數、上限、綠寶石配料與既有補貨期限。配方與新掉落直接使用新模板。

### 武器與種族

- 八武器按 [武器表](data/BALANCE_WEAPONS.csv) 的攻速正規化，完整普攻含主屬性部分一起換算。法杖右鍵普攻使用同一快照，不占主動技能追加池；間隔約0.715秒。
- 原版手持攻速經暫時修飾調整到對應模型，換手後更新；停用／離線清理本插件的修飾，保留其他插件的修飾物件。空手傷害為劍基準的35%。
- 普攻蓄力係數為 `.2＋.8×冷卻比例²`；暴擊只算一次。基本暴率5%＋每AGI0.1百分點，上限30%；暴傷1.5，上限1.75。
- 種族、天賦屬性、武器專精、稀有度、武器親和、額外暴率與增傷附魔，合計常駐單擊期望輸出最多比角色本身配點／裝備基底高10%。暴率／暴傷效果會占此預算。
- 鋒利、力量、穿刺每級提供最多1%的常駐傷害預算，單項最多5%；一般保護附魔每級轉0.25額外防禦評分，單件最多2，合計仍受額外防禦上限5限制。
- 十二種族仍保留技能、選擇與取向；六屬性總加成為 `18＋floor(18×(L−1)/59)`，Lv.1 合計18點、Lv.60合計36點。基礎18點依 base-stats 分配（正權重先保留1點），額外0～18點依 growth 分配；採固定權重逐點分配，升級不會扣回任何一項。種族暴率最多1百分點、暴傷最多0.05、常駐移速最多±3%、武器親和98%～102%；額外MP最多10、回魔最多0.25/s。GUI列表及詳情顯示玩家目前等級的種族額外加成；成長頁顯示Lv.1／30／60實際預覽，避免把權重誤讀成每級倍率。自訂零權重仍保留為零。

## 4. 技能、種族追加效果與回血

初始接法保留現有招式／冷卻／範圍，並在共用傷害管線限制其數值；這不是逐一重新設計164個天賦。

- 舊技能傷害先按 `sqrt(同級參考DPS / Lv.1參考DPS)` 轉換，再受每位攻擊者對每個目標共用的追加傷害池限制。
- 追加池初始最多可造成約2秒基準 DPS 的爆發，之後每秒補0.15秒基準 DPS。技能、召喚物、流血、燃燒、條件觸發、種族主動增傷、破甲與分裂箭共用，避免每個來源各自再翻倍。
- 普攻沿用發射／攻擊時的基準 DPS；延遲技能的基準採角色等級與自身主攻取向，獨立於命中瞬間所持武器，避免切手重領傷害額度。法杖與弓本身有不同輸出係數，因此不能把所有流派都宣稱成精確「+25%」。
- 狀態、控制、範圍及實際目標上限仍依既有執行器；AoE 的每個目標各有自己的追加池，未新增全場總傷害上限。控場、多人同時施法及清怪效率仍需測試服調整。
- 成功傷害才結算追加額度。取消傷害會退還預留額度；吸血及武器追加效果延至成功事件後處理。汲取類治療按實際扣血計算。
- 追加池有閒置回收及4096組上限，角色重連保留同一服務內的已用傷害額度；不持久化跨伺服器重啟的短期戰鬥額度。
- 天賦主動技能已依使用者要求恢復設定檔的固定 `manaCost`，例如20就固定扣20 MANA，與最大MP及冷卻長短無關；原本零耗魔維持零。機制物品與快捷鍵共用檢查、扣魔及冷卻，GUI與不足魔力提示顯示固定MANA。種族技能與既有武器技能的資源／冷卻入口保留。
- 自製生命藥水另走可取消的 CUSTOM 治療事件，固定40／120／280HP、與魔力藥水共用15秒持久冷卻；不重複占技能的25%單次上限與短期池。魔力藥水固定恢復30／80／160MANA，上限照常限制，見 [POTIONS.md](POTIONS.md)。
- 戰鬥中治療單次最多25% HP，短期池最多35% HP，之後每秒可補4% HP；取消治療退額度。原版瞬間／持續治療先依 HP 單位換算。自製暗黑／能量護盾使用比例吸收量。
- 原版飽食回血關閉，由共用脫戰回復計時器處理：最近8秒無戰鬥後約每秒5%最大HP，種族額外最多再0.5%；天賦被動回血僅在脫戰時作用。登入會重新等待8秒。
- 第二春按減傷後致死判斷，加入60秒冷卻；變身、換裝與天賦重算保留當前血量比例。

這些池限制數值，不替代 WorldGuard／PvP／隊伍／視線等施法資格檢查。既有非傷害控制能力仍可能影響 Boss 壓力，需要實機測試。

## 5. 怪物與傷害結算

- 自製怪與已載入／後載入的原版 `Enemy` 取怪物等級／所在地區等級，套同一模型；不依攻擊者目前配點動態補強怪物。
- 普通怪：`HP=參考DPS×5`、原始攻擊=`參考HP/[6×(1−參考DR)]`。
- 自製 `boss: true` 預設荒野 Boss；`elite` 標籤或 ID 含elite採精英；`group-boss` 標籤採隊伍 Boss。倍率沿用模型：精英有效HP×3／攻擊×1.35，荒野Boss×14／×1.4，隊伍Boss×24／×1.4。
- 隊伍 Boss 第一次被玩家攻擊時，固定48格內合資格生存／冒險玩家人數1～8，HP乘 `1＋.75×(N−1)`。離線／加入不反覆重設HP，傷害不隨人數倍增。
- 已載入舊怪按當前剩餘血量比例換算，標記v2；不因重啟補滿。舊自製怪超出60的等級與名稱前綴轉為60。
- 普通攻擊成功命中後至少間隔1.8秒；原版 AI 可能使間隔更長。怪物技能每來源／目標最多先爆發2.5次基準攻擊量，再每秒補0.4次，保留預警招式與走位壓力。
- 直接戰鬥由 RPG 防禦取代原版盔甲、保護與抗性減傷，避免再疊原版百分比；盾牌格擋與吸收量仍保留。部分專用附魔與外部插件的傷害修飾需要相容測試。
- 玩家環境傷害依最大HP／20換算，保留原版環境減免；怪物環境傷害依同級普通怪HP換算，避免Boss被百分比火傷瞬間融化。玩家施加且可追蹤的燃燒受追加池限制。
- 護甲與盾的耐久損耗按 `20/玩家最大HP` 換成原版等價單位，至少1；武器／工具耐久維持原流程，避免高等RPG傷害讓護甲數刀就壞。

### 虛擬 HP

大於1024的怪物保留實際 RPG HP，原生HP僅投影其比例：

```text
RPG最終傷害100 → 虛擬HP扣100
原生事件扣血 = RPG最終傷害 × 原生最大HP / 虛擬最大HP
```

原生事件不取消、不額外合成致死傷害，保留 Paper 的死亡、擊殺歸屬與掉落流程。MONITOR 階段確認未取消才更新虛擬HP；多次命中依當前HP扣除，治療同理。吸收量維持RPG單位消耗，僅剩餘傷害按比例投影；傷害數字轉回RPG單位顯示。

依 [Paper 1.21.11 EntityDamageEvent](https://javadocs.papermc.io/paper/1.21.11/org/bukkit/event/entity/EntityDamageEvent.html) 的原始／最終傷害區別實作；相容層仍使用該版本的 deprecated DamageModifier API，更新 Paper 大版本時需要重新核對。

## 6. 驗證與排查

最新固定耗魔與種族修正：`mvn verify` **441 tests，0 failures／errors／skipped**，紀錄 `target/fixed-mana-race-verify.log`。追加測試包含固定耗魔不隨最大MP增加、免費技能、十二族720個等級組合的非零／守預算／單調性、重新套用不疊加／不補魔，以及GUI目前等級與成長預覽。

原始戰鬥v2階段 `mvn clean verify`：415 tests，紀錄 `target/balance-runtime-clean-verify.log`，新增七類／48案。測試包含：

- 不重複遷移、配點守恆、不可寫備份、原子替換失敗重試、較新版本拒絕與MP比例。
- 六件裝備所有等級合計預算、舊高倍率武器正規化、種族／天賦持久來源分離。
- 實際最終監聽器 Lv.1～60 非暴擊劍皆需7刀，裝備防禦與原版減傷不重算、護甲耐久換算。
- 近戰／投射物快照、延遲技能切手不提高額度、重連不重領、取消傷害／回血退額度。
- 虛擬HP一比一扣血、同tick多次命中、原生致死來源、吸收量與治療取消。

測試用 mock 事件驗證管線與數學，沒有建立虛假的全域 Paper RegistryAccess。通過 Maven 不等於真實無敵幀、AI、多人交易、伺服器插件與數值平衡已驗收。

在 `plugins/CustomRPG/config/config.yml` 加入並重啟可記錄已接受傷害：

```yaml
balance:
  debug-damage: true
```

日誌 `[Balance:v2]` 包含來源／目標 UUID、減傷後RPG傷害與投影後原生傷害。完成排查後關閉，避免戰鬥日誌過量。

部署後優先測 Lv.1／8／18／28／38／48／58／60：普通單挑、三怪群、荒野Boss、隊伍Boss、法杖、飛行種族、盾牌／吸收、變身中升級換裝、重啟與舊物品交易。測中位數及P90擊殺時間，並確認保護插件取消後沒有扣血／吸血。PvP 使用同一屬性管線，但初始模型的4～6秒目標僅對單人PvE普通怪。

## 7. 還原

自動備份是玩家／天賦檔遷移前的原始內容，不是世界備份。需要回到舊數值時停服、換回原JAR，並將對應備份還原成原UUID檔名；保留整套同時期資料可避免玩家與天賦狀態不一致。已更新並保存在區塊內的生物HP也需要世界備份或重新生成；只換JAR不會自動撤銷實體狀態。
