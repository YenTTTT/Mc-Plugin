## 學習與施放

1. 更新 `target/CustomRPG-1.0.jar` 並重啟後，插件會自動補建 `plugins/CustomRPG/config/talents_additional.yml`；不用把新內容手動貼進舊設定。
2. `/talent` 可看見全部十四個流派，或用上表指令直接開啟。先學最下方的入門被動，再沿前置學主動招式；滿足前置的一級即可解鎖下一招。
3. 在天賦樹將滑鼠指向已學主動招式，按數字鍵 **1～4** 綁定；關閉介面再按相應鍵施放。技能列預設開啟，`/skillbar` 切換。被動不占技能槽；**5 仍固定為種族技能**。
4. 新招式也可手持機制物品右鍵施放：冰霜＝海磷碎片、雷霆＝海靈晶體、大地守衛＝燧石、聖光＝螢石粉。先攜帶至四個槽；蹲下右鍵循環同物品的技能。快捷鍵仍可空手施放，兩種入口共用冷卻與設定檔 `manaCost` 固定 MANA 消耗；傷害、治療依戰鬥 v2 管線計算。
5. 管理員可用 `/talent give <玩家> 24` 提供測試點數。原版選取快捷欄事件仍有滾輪也會觸發的限制，詳見 [技能快捷鍵](../SKILL_SWITCH_SYSTEM.md)。

每個新流派有四招主動，可全部放入 1～4，也可跨流派搭配；沒有新增強制職業鎖或換掉既有技能。基本消耗與冷卻在下表，升級改變效果，不降低冷卻或魔力消耗。

## 戰鬥細節

- 冰霜：冰晶射線緩速 2／2.5／3 秒；碎霜長槍對已緩速目標加傷 35%。凜冬風雪固定於施法位置，半徑 3.5／4／4.5 格，持續 5／6／7 秒。新招式施加在自訂 Boss 身上的緩速時間減半，沒有硬性凍結或修改地形。
- 雷霆：電弧最多 3／4／5 個不同目標，每跳傷害乘 0.8，跳躍檢查距離與視線；首個目標未受有效傷害便不繼續跳躍。閃步水平移動最多 3／4／5 格，逐段確認模型空間、邊界、保護區、液體與已載入區塊；受阻縮短距離，無空間或傳送被取消時不扣魔力／不進冷卻。閃步不是飛行，沒有免摔落保護。
- 大地：岩甲六秒減傷 20%／25%／30%；堡壘半徑 4／4.5／5 格，持續 6／7／8 秒，陣內自身及可見同隊玩家減傷 15%／20%／25%。岩甲與多個堡壘取最高減傷，不能堆成無敵；仍與既有防禦／其他技能各自處理。不抵擋虛空、KILL 或 SUICIDE 傷害。岩脈束縛需要瞄準射程內的方塊。
- 聖光：微光瞄準同隊玩家，無有效隊友時治療自己；沒有隊伍也能自療。淨化只清除自身的中毒、凋零、緩速、虛弱、失明與黑暗，不移除其他藥水。黎明聖域固定於施法位置，每秒治療自身與可見同隊玩家，半徑 4／4.5／5 格，持續 5／6／7 秒。微光在滿血或治療遭取消時不扣資源；淨化在既無可清除效果、也未成功治療時不扣資源。

同隊以施法者 scoreboard team 成員為準。新攻擊招式不傷害同隊、馴服寵物、展示盔甲架、無敵目標、創造／旁觀玩家；玩家互攻還需世界開啟 PvP。傷害檢查本插件安全區與保護區、球形範圍及遮擋，透過 Bukkit 事件／既有虛擬 HP 管線；沒有有效扣血便不追加緩速／擊退。治療送出可取消的 CUSTOM EntityRegainHealthEvent，沒有直接繞過領地或傷害保護。

每次範圍攻擊最多 32 個敵人，治療領域每次最多處理 16 名附近玩家。持續領域全服最多 64 個、每位玩家最多三個；同人同招重放替換原領域，沒有額外疊加。領域共用每五 ticks 的計時器，每秒脈衝，延遲不補發漏掉的傷害／治療。死亡、離線、成功傳送、模式切換、天賦重置、成功重載與插件停用均清除新領域／岩甲；領域區塊卸載也會停止。附加的短效緩速由原版藥水時間到期，不強制刪除其他來源的藥水。

新傷害基礎計算 `baseDamage + 總魔力×magicScaling + 總力量×strengthScaling` 上限 200，再套碎冰／不死條件加傷；新治療 `baseHeal + 總精神×spiritScaling` 上限 100，再交給治療事件與最大生命限制。各級係數可查看天賦圖示或設定檔。八個被動透過既有天賦屬性計算整合，重置會撤回，沒有每次登入重複累加的獨立新屬性來源。

## 設定升級與重載

`config/talents.yml` 原有同 ID 定義優先，整個天賦定義覆蓋 additional 檔的同 ID，不逐欄位混合。舊天賦、玩家投點與四槽綁定保留，不自動學新天賦或改動舊天賦數值。原本的 `warrior`／`mage` 指令別名現在對應武器／烈焰分支，Tab 列出十四個真正的分支。

`/talent reload` 現在真正重讀兩份設定：先驗證再交換天賦樹，失敗保留上一份有效設定、正在運作的新領域及檔案原文。新增流派驗證數值範圍、完整等級、已接線的效果／技能、GUI 重複欄位與前置循環；不支援只在 YAML 發明新技能 ID 便自動獲得執行器。

成功重載會重新套用線上玩家的天賦屬性與被動、關閉天賦介面並清除本輪新招式的持續狀態；既有天賦記憶體冷卻保留。插件重啟仍依既有設計清除天賦冷卻，持續領域／岩甲不跨重啟；本輪沒有遷移或重寫所有舊天賦計時器，也沒有將玩家不同 YAML 檔改成資料庫交易。
