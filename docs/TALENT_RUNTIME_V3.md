## 玩家操作

1. `/talent` 開啟八大主題，點主題就直接顯示該系十個新版核心技能；例如「武器」會顯示弧月斬、震地破擊、貫穿突刺、迴旋斬舞及千刃風暴等。
2. 核心頁左鍵學習；右鍵已學主動技能，點下方普通槽或大絕槽攜帶。滑鼠指向普通技能按 1～4 也可綁定。
3. 核心頁下方「舊天賦／特色專精」按鈕可進入保留的原流派；舊頁右鍵主動技能同樣可選攜帶槽。`/talent hunter` 保留六個角色／共通修行分頁。
4. 關閉介面，將武器放在快捷欄 6～9。技能模式預設開啟，`/skillbar` 切換。

| 預設按鍵 | 技能模式中的用途 |
| --- | --- |
| 1～4 | 普通技能一至四 |
| F（交換副手） | 第五普通技能 |
| Shift＋F | 獨立大絕；奧術回溯的有效期間內可再按一次 |
| 5 | 種族主動技能 |
| 6～9 | 選取實際武器或物品 |
| 技能指定機制物品 | 主手按指定方式施放；蹲下右鍵循環該物品的已攜帶技能 |

關閉技能模式時恢復原版快捷欄與副手交換。F 遵循客戶端的交換副手綁定；1～5 使用快捷欄選取事件，滾輪選到也會施放。不同入口共用已學習、攜帶、冷卻、MP／HP、目標與區域檢查。舊物品材料保留，核心依主題使用武器／烈焰粉／蜘蛛眼／螢石粉／紅石／木棒／紫水晶碎片／骨頭，確切按鍵以技能介面為準。

可直接使用 `/talent core <主題ID>`：`weapon`、`elemental`、`shadow`、`light`、`blood`、`nature`、`arcane`、`summoning`。原有 `/talent frost`、`/talent sukuna` 等指令仍開啟舊路線。

## 學習規則與效果

每主題十節點：四普通主動、兩被動、兩屬性、一強化、一大絕；合計 **32 普通主動、8 大絕、40 個自動生效節點**。核心全部單級；普通／被動／屬性一點、強化二點、大絕三點，每系全學十三點。

| 層級 | 最低角色等級 | 額外要求 |
| --- | ---: | --- |
| T1 | 2 | 節點指定前置 |
| T2 | 10 | 節點指定 ALL／ANY 前置 |
| T3 | 20 | 指定連動前置 |
| T4 大絕 | 35 | 指定前置及本系核心已花八點，再支付三點 |

本系八點排除大絕本身及舊路線投點。普通槽拒絕核心大絕，大絕槽只接受核心大絕；同技能不重複占槽。戰鬥後八秒內不能更換攜帶配置。舊 ACTIVE 在相容版仍按原類型使用普通槽，尚未強制轉成專精大絕。

四十個可施放核心節點均有執行器，涵蓋斬擊／連段、元素標記與連鎖、繞背與匿蹤、治療／護盾、生命交換與實際吸血、藤蔓／孢子、符文與安全回溯、召喚及八大絕。被動、屬性與強化由學習狀態判定，不另外綁定。詳細逐招成本與效果見 [80 節點 CSV](data/TALENT_REDESIGN_NODES.csv)。

傷害沿用戰鬥 v2 共用追加池；正規化核心倍率不再重複套舊技能傷害縮放。吸血依成功傷害的實際 HP 損失計算，不把取消傷害或純吸收損失當作生命汲取；新核心吸血每秒至多本人最大 HP 的 3%，治療仍受既有治療服務限制。護盾與原版吸收合計最多目標最大 HP 的 15%。HP 成本必須保留至少 2 HP；不花 HP 的救援技能可在低血量時使用。

普通持續效果全服至多 64、每人三個；同人同招重放替換舊者。大絕同時至多八個；新核心召喚全服至多 64、每人一個，雙生契約後可帶兩個不同種類。滿額拒絕或起手目標／落點失效會退還本次資源。召喚分別為石衛、粒子治癒精靈及影狼，幻龍只畫粒子，不生成真龍或改方塊。

所有 Bukkit 世界操作使用主執行緒。每五 ticks 檢查狀態，以單調時間計冷卻及期限；延遲時不補打錯過的波次。粒子每次至多 64 個位置，施法者每秒 384、觀看者每秒 768；24～40 格降低採樣，40 格外不送。這些是執行限制，實際 TPS 與觀感仍需實服量測。

死亡、登出、成功傳送、切模式、變更配置／重置、成功重載與停用會清理核心暫態效果、控制與召喚；保留記憶體冷卻，重登不洗 CD。插件完整重啟會清除核心冷卻，未新增跨重啟冷卻存檔。

## 設定與玩家資料

更新 JAR 並重啟後自動補建 `plugins/CustomRPG/config/talents_core.yml`；原三份天賦設定不覆寫。核心設定在完整通過節點數、類型、點數、數字、前置無循環及格子驗證後才整批發布。初次載入無效設定會使初始化失敗；管理員 `/talent reload` 失敗時保留先前有效定義。

天賦檔使用 `loadout-version: 3`，五格 `selected-skills` 加獨立 `ultimate-skill`。讀取舊四槽保留原順序及空格，第五槽和大絕留空；保留所有舊 ID／等級，不做概念對照別名替換。首次寫入舊版檔之前，原檔備份至 `plugins/CustomRPG/data/talent-backups/v3/`。無法安全載入或版本高於三的檔案拒絕覆寫。

此版沒有批次轉換舊投點、免費洗點或跨屬性檔／天賦檔的交易 journal。若之後要正式收斂舊普通路線與新核心，仍須完成只讀預覽、點數守恆、轉換確認與故障恢復。回退 JAR 時應停服並還原對應備份，不能把含新版 ID 的檔案直接交給舊版讀取。

維護用的 `python tools/talents/export_core_definitions.py` 可從已審核 CSV 匯出 bundled 核心 YAML；變更效果文字不會自動生成技能程式，需同步修改對應執行器與驗證。現有部署設定不因重新匯出而自動覆寫。
