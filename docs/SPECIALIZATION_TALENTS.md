# 特色專精天賦一覽：八十核心以外的現有內容

2026-10-23。依工作區舊版天賦設定整理，**95 個天賦：64 主動、31 被動**，保留原技能／數值說明。

八大主題與80核心已撤除，所有流派恢復 `/talent` 直接入口。本表列出宿儺、風獵者弓箭、野獸、科技、獵人念能力五組特色內容；其他十個舊流派同樣保留，總共15流派／200天賦。使用方式與存檔相容說明見 [舊版恢復說明](TALENT_LEGACY_RUNTIME.md)。原八大主題設計與新舊對照僅作歷史資料，不表示目前仍有合併或核心技能。

完整可篩選表：[SPECIALIZATION_TALENTS.csv](data/SPECIALIZATION_TALENTS.csv)。

說明來自目前 bundled YAML，描述的是現有技能概念；倍率、範圍及逐級變化以設定與實際執行器為準，輸出／治療仍受[戰鬥 v2](BALANCE_RUNTIME.md)限制，不能把「百分比生命」「倍增」「軍團」直接理解為無上限效果。尚未逐招進行 Paper 實服驗證。

**主動**需要已學習及攜帶後施放；**被動**學習後自動生效，不能綁成主動技能。下表保留目前類型與最高等級，沒有提前套用重設計中的單級節點或大絕分類。
